# Horizon: Wake Up

A third-person bullet-time action game. Horizon, a teenager in a hoodie with headphones around the neck, discovers the school day is a simulation. Fight through the classroom, hallways, cafeteria, gym and rooftop, unlocking Focus, Dodge, Code Sight, Stop and Return, then face the Principal, the simulation's guardian, in the office wing. A crew of three awakened friends fights alongside you, and a second Xbox controller can take one of them in co-op.

Play in the browser: open `index.html`, or use this repository's GitHub Pages link. It is one offline file with no account and no network.

Controls (Xbox controller, keyboard and mouse, and touch) are in `CONTROLLER.txt`. Test results are in `TEST_REPORT.md`. Three.js is included under the MIT license (`THREEJS-LICENSE.txt`).
